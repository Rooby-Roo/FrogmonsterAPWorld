# AI Use Disclosure
TL;DR: My very early work on the project contains some small AI assistance. All of my following work, and all work done by Ben for the client, contains no AI usage.
## For the .apworld:
The .apworld was developed exclusively by myself. I claim the following about AI usage on the project:
- No AI-generated assets are used in any capacity.
- No AI was used in the drafting, conceptualizing, or designing of the project.
- No AI-powered tools are currently being used in the programming of this world. However, _some_ AI assisted-coding has been historically used with the project. Early on in the development cycle, I was using the default suite of tools provided by a stock build of VSCode. This includes AI-powered "autocomplete" functions. Additionally, I have occasionally used the integrated Copilot window for diagnosing and troubleshooting purposes. Sometime after my first release of the Frogmonster world, I disabled these tools, as I felt as though they interfered with my ability to improve as a developer, and because I came to dislike the moral implications of using them.
- No AI was used in the writing or editing of any supplementary documentation.

I assert that all code in the .apworld project is entirely my own, except in cases where git history, license, or code comments attribute other people. I cannot speak with entire confidence on the work of other people in regards to how AI is used, but I will insist that all contributions meet the requirements I lay out in `contributing.md`. I will not accept work into my repositories that I know breaks these guidelines.

## For the game client:
The game client was developed entirely by Ben Jungwirth, the primary developer of Frogmonster. When asked about whether or not he used AI in the development of the Frogmonster client, Ben responded with the following statement (quoted verbatim):
> Didn’t use any ai at all so we good either way
> 
> I like programming and art by people. Will continue to make things that way

# Contributing with AI
If you are a developer who wants to know to what extent AI use is acceptable in contributing to this project, please see `contributing.md`.
