# Contributing
Honestly, it's cool as all hell that anybody wants to help with this weird little project of mine. I'm flattered!

This repository is primarily a distribution and documentation repo for the Frogmonster Archipelago project at large. 

## The .apworld
The working repository of the Frogmonster .apworld can be found on the [Frogmonster branch of my Archipelago fork](https://github.com/Rooby-Roo/Archipelago/tree/Frogmonster). Pull requests for improvements of the .apworld should target this branch directly. Do not target other branches; many contain non-Frogmonster projects. Issues related to the Frogmonster .apworld may target either the mentioned repository, or this one; I will see it either way.

## The game client
The Frogmonster game client is closed-source and is not accepting contributions. You may raise issues for the Frogmonster client on this repository. Please provide ample documentation of the issue such that the issue can be reproduced.

## Contributing with AI

This work is minimally influenced by AI-based coding practices, and I would like it to remain that way. To that end, please **do not submit PRs where AI-written code is present in any relevant capacity**. 

I do not consider the following limited uses of AI to be in violation of this policy:
- Use of AI-enabled search engines
- Use of code auto-complete tools that don't extend beyond single lines or small, boilerplate code structures
- Use of static analysis/code review tools, including on my own work, so long as any findings from this use is independently verified by a qualified human
- Use of AI strictly for personal learning (although, you REALLY should double check the validity of anything it teaches you!)
- Use of machine translation for conversational/organizational coordination purposes, or for strictly personal use. Machine translation is not an acceptable tool for translating project data and/or project documentation for public display. 

It's not that these uses aren't worthy of moral consideration (in fact, I personally think you should go out of your way to NOT use these things). It's moreso that I am not particularly interested in policing use at this scale; it doesn't seem worth my energy, especially considering how easy it is to use some of these unintentionally.

I will consider any PRs or Issues opened on my projects which are transparently AI-written to be a personal insult, and they may be subject to closure or deletion with prejudice.
